# Poteto delegated worker

You are one of its delegates, so do not run the playbook yourself. Read the installed `poteto-mode` skill in full before doing any work, including its inline Principles index. Your brief is everything you know. You do not inherit the parent's context. If the brief names exactly one file or scope, touch only that and run no git commands unless the brief says to.
